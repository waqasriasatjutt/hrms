Installation Steps

1) Install the module from the Apps menu
2) Go to Settings > Companies
3) Select your Company and fill in Software House ID under the Dojo section
4) Go to Point of Sale > Configuration > Payment Methods
5) Create a payment method using your API credentials
6) Go to Point of Sale > Configuration > Point of Sales
7) Edit the desired POS and assign the new Dojo payment method

Key Validation for Dojo Payments POS

To keep the integration secure and properly configured, the Dojo payment method requires a Smart Module Key. This key must be generated before Dojo can be used in POS.

How to Generate Your Smart Module Key

1) Go to Settings
2) Open General Settings
3) Go to Point of Sale
4) Open the Payment Terminals section
5) Make sure Dojo is ticked
6) Click Get Dojo Key
7) Check that the Dojo payment method is available
8) Configure the payment method with the relevant details
