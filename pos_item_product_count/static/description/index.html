Key Features

Unique Product Count

Displays the number of distinct products added to the POS order, regardless of quantity.

Total Order Lines

Shows the total number of order lines in the current POS transaction.

Live Quantity Calculation

Automatically calculates the total quantity of all products as items are added or updated.

Seamless POS Integration

Integrates directly into the POS Order Widget with no configuration or setup required.
