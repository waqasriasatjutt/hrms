POS Configuration Comptable du Point de Vente

Configuration avancée des paramètres comptables pour votre Point de Vente Odoo. Gestion des clients par défaut, taxes et écritures de clôture.

👥

Client par Défaut Obligatoire

Configuration obligatoire du client par défaut pour les journaux de type vente

📦

Écriture de Clôture par Produit

Option pour afficher la répartition des ventes par produit dans les écritures

Configuration Comptable du POS

Après installation du module, accédez aux paramètres comptables du Point de Vente pour configurer :

  • ✓
    Client par défaut - Obligatoire si le journal des commandes est de type "Vente"
  • ✓
    Écriture de clôture par produit - Option à cocher pour un détail par produit dans la facture

Fonctionnalités Clés

👤

Gestion des Clients

Définissez un client par défaut pour toutes les sessions POS. Si aucun client n'est configuré, le système redirige automatiquement vers les paramètres.

⚙️

Intégration Native

Fonctionne parfaitement avec le module Point of Sale natif d'Odoo sans nécessiter de configurations complexes.

Version du module : 18.0.0.0.0 | Compatible Odoo v18

Installation et Configuration

Après installation du module, configurez les paramètres comptables du Point de Vente :

Étapes de Configuration

1
Allez dans Paramètres → Point de vente → Comptabilité
2
Définissez le client par défaut pour les journaux de vente
3
Cochez "Écriture de clôture par produit" si nécessaire
4
Sauvegardez les modifications
