Install & Activate

  1. Drop the module into your Odoo addons folder.
  2. Restart the Odoo server.
  3. Apps → Update Apps List → search "WT Theme Fashion" → Install.
  4. Website → Configuration → Themes → activate.
  5. Edit copy and images in the page builder. Publish.
