Overview

This module helps you in pharmaceutical industry. allows you to manage pharmaceutical data.

Features

Pharmacy management functionality provides a structured way to manage patients, doctors, medicines, and prescriptions.

This module allows users to create and organize patient uniq id, date of birth, age and gender also doctor medical License and specification.

You can manage medicines info stock and prescriptions related informations.

Configuration

    After installing the module, a new "Pharmacy" menu will be added.

  • MANAGE PATIENT

    • Go to Pharmacy -> Contects -> Patients, Inside patient you can manage patients from this view.

    Create and view patient detail.

  • MANAGE DOCTOR

    • Go to Pharmacy -> Contects -> Doctors, Inside doctors you can manage doctor from this view.

    Create and view doctor detail.

  • MANAGE MEDICINES

    • Go to Pharmacy -> Contects -> Medicines, Inside Medicines you can manage medicine from this view.

    Create and view medicines.

  • MANAGE PRESCRIPTION

    • Go to Pharmacy -> Contects -> Prescriptions, Inside Prescriptions you can manage Prescription from this view.

    Create and view Prescription.

    You can see all the details like patient, doctor and medicines. manage stage of the record.

    In the medicines page you can add all the details related to the drugs.
