Configuration

Employee Restaurant Access Rights Configuration

Navigate to HR > Employees > Select Employee > POS Access Rights Tab to configure restaurant-specific access restrictions for each cashier.

Restaurant Actions Popup

Control restaurant-specific action buttons in the Actions popup.

After - Split Button Hidden

Hide Guests Button

Before - Guests Button Visible

Floor Access Control

Control which floors employees can access in the restaurant POS.

Disable Specific Floors

Select specific floors that should be hidden/disabled for each employee in the restaurant POS. This allows you to restrict employees to certain areas of the restaurant.

Before - All Floors Accessible
After - Selected Floors Disabled
