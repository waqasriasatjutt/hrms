WT CRM Analytics Dashboard

Enterprise CRM Analytics for Odoo 18 — 9 KPI cards, pipeline charts, lead source analysis, sales rep performance & period comparison.

Live Dashboard Preview

This is the actual dashboard — exactly what you see after installation.

Getting Started

Up and running in minutes.

1
Install Module

Install WT CRM Analytics Dashboard from Apps. Only CRM and Web are required — no extra dependencies.

2
Open Dashboard

From the Odoo home screen click CRM Analytics. The dashboard loads instantly with live data from your full CRM pipeline.

3
Apply Filters

Use the top-bar filter strip to select a period, then optionally narrow by Salesperson and Pipeline Stage. Click Refresh to reload all data.

4
Explore Tabs

Switch between tabs: Overview (pipeline funnel, lead trend), Financial (revenue by stage, won/lost ratio), Sources (lead origin breakdown), Reps (salesperson league table) and Comparison (period vs period).

Module Features

Everything you need to understand your crm performance — all in one place.

📈
9 Live KPI Cards

Pipeline Value, New Leads, Won Opportunities, Lost Ratio, Expected Revenue, Activities Due, Avg Deal Size, Conversion Rate and Open Opportunities — all with period-over-period change indicators.

📊
Pipeline Funnel Chart

Visual funnel showing lead volume and value at every stage — New, Qualified, Proposition, Won. Identify where deals stall and where to focus sales effort.

👥
Salesperson Performance

Top-performing reps ranked by won revenue, conversion rate and deal count. Identify your best closers and spot under-performance early.

🔍
Smart Filters

Filter by Today, Last 7 Days, This Month, This Quarter, This Year or a custom date range. Stack with Salesperson and Stage filters for precise pipeline drilldowns.

🔁
Period Comparison

Compare current period pipeline value, won deals, new leads and conversion rate against the equivalent previous period with side-by-side charts and delta indicators.

🎯
Lead Source Analysis

Break down your pipeline by lead source — website, email, phone, partner — to see which channels deliver the highest quality opportunities.

📋
Activity Tracking

See overdue activities, upcoming follow-ups and meetings at a glance. Never let a hot lead go cold due to missed follow-up.

💲
Won & Lost Analysis

Understand your win/loss ratio by stage, salesperson and time period. Drill into lost reasons to improve your sales process.

📱
Fully Responsive

Works on desktop, tablet and mobile. KPI cards reflow from 3 columns to 2 to 1, tabs collapse and all charts resize fluidly.

How to Use — Step by Step

A complete guide to getting the most out of your crm analytics.

1
Install the Module

Go to Apps, search for WT CRM Analytics Dashboard and click Install. Only CRM and Web are required — all dependencies install automatically.

2
Open the Dashboard

From the Odoo home screen click the CRM Analytics app tile. The dashboard opens instantly, loading all KPIs, charts and data for the default period (Today). Access is restricted to users with the CRM / Manager or Salesperson role.

3
Set Your Filters

Use the top-bar filter strip to select a period, then optionally narrow by Salesperson and Pipeline Stage. Click Refresh to reload all data.

4
Explore the Tabs

Switch between tabs: Overview (pipeline funnel, lead trend), Financial (revenue by stage, won/lost ratio), Sources (lead origin breakdown), Reps (salesperson league table) and Comparison (period vs period).
