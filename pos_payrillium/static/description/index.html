Payrillium Payment Integration

Seamless Payment Terminal Integration for Odoo POS

This module provides comprehensive integration between Payrillium physical payment terminals and Odoo Point of Sale (POS) system. It enables merchants to process payments directly through Payrillium devices, manage payment terminals, process tokenized card payments, create payment links, and handle refunds with full session-scoped terminal selection.

Key Features

  • Physical Terminal Support: Connect and manage Payrillium payment terminals directly from your POS sessions.
  • Tokenized Card Payments: Process payments using saved customer card tokens for faster checkout.
  • Pay-by-Link: Generate secure payment links for invoices that customers can pay online.
  • Session-Scoped Terminal Selection: Assign specific terminals to POS sessions for better control and organization.
  • Refund Management: Process refunds directly through the integrated payment system.
  • Automatic Payment Sync: Optional automatic synchronization of payment statuses via scheduled jobs.
  • Payment Link Management: View and manage all payment links with status tracking (active, paid, expired, inactive).

Requirements

This module requires a Payrillium/Mirillium account and API token for full functionality. The module can be installed without a token, but payment processing features will require proper configuration.

After installation, you will be prompted to configure your Payrillium credentials through a setup wizard.

Installation & Configuration

  1. Install the module from the Odoo Apps menu
  2. Complete the configuration wizard with your Payrillium API token
  3. Configure accounting accounts (receivable and outstanding payment accounts)
  4. Add the Payrillium payment method to your POS configuration
  5. Assign terminals to POS sessions as needed

Technical Details

The module integrates with the Payrillium/Mirillium API for terminal management, payment processing, and transaction synchronization. All sensitive credentials are stored securely and are not exposed in logs or responses.

The module follows Odoo best practices and does not require vendor lock-in. It can be installed and uninstalled without breaking your Odoo instance, and all data remains under your control.
