Install & Activate

  1. Download the module zip and drop it in your Odoo addons folder.
  2. Restart the Odoo server.
  3. Apps → Update Apps List → search "WT Theme Construction" → Install.
  4. Website → Configuration → Themes → pick "WT Construction" or run the website configurator.
  5. Edit copy and images in the page builder. Publish.
