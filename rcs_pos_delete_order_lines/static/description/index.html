Detailed Features

Intuitive Single-Line Removal: The default Odoo Point of Sale requires users to select a line and press the backspace key, which can be inefficient. Our module upgrades this process by adding a visible "cross" icon directly on the right side of each order line. This simple addition to the POS billing software makes the process of removing a single product self-explanatory and incredibly fast
Efficient "Clear All" Functionality: For situations where an entire order needs to be canceled, our app adds a "Clear All" button to the main POS screen. Instead of deleting each line one-by-one, cashiers can now clear the entire cart instantly. This is a critical feature for any effective order management system, saving valuable time during busy periods.

Work Flow

Standard Odoo POS Workflow:
  • Add products to an order.
  • To remove one item, click the specific order line.
  • Press the 'Backspace' key on your keyboard. OR Press 'x' icon.
  • Repeat for every item you need to remove.
New & Improved Workflow with our App:
To Remove a Single Item:
  • Add products to an order.
  • Simply click the 'X' icon next to the line item you wish to remove. The item is instantly deleted.
To Cancel the Entire Order:
  • Add products to an order.
  • Click the 'Clear All' button on the screen to remove the order completely.
