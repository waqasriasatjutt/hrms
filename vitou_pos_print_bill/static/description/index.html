Display Bill Button Near Action Button

This module is Displayed Bill Button Near Action Button in POS Restuarant.

Manual how to setup and use.

  1. Extact Zip the File
  2. Copy and Past in folder custom_addons
  3. Restart Odoo Service
  4. Login Odoo as system administrator
  5. Navigate to Apps
  6. Update Apps List
  7. Search as keyward vitou or POS Print Bill
  8. Click Activate
  9. When you sale in POS Restaurant, you will see the new button Bill next to Action Button
