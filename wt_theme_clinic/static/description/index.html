Install & Activate

  1. Drop the module zip into your Odoo addons folder.
  2. Restart the Odoo server.
  3. Apps → Update Apps List → search "WT Theme Clinic" → Install.
  4. Website → Configuration → Themes → activate WT Clinic.
  5. Edit copy, doctor photos and contact details in the page builder. Publish.
