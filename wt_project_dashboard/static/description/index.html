WT Project Analytics Dashboard

Enterprise Project Analytics for Odoo 18 — 9 KPI cards, task progress, deadline tracking, team performance & timesheet analysis.

Live Dashboard Preview

This is the actual dashboard — exactly what you see after installation.

Getting Started

Up and running in minutes.

1
Install Module

Install WT Project Analytics Dashboard from Apps. Only Project and Web are required — no extra dependencies.

2
Open Dashboard

From the Odoo home screen click Project Analytics. The dashboard loads instantly with live data from all your active projects and tasks.

3
Apply Filters

Use the top-bar filter strip to select a period, then optionally narrow by Project and Assignee. Click Refresh to reload all data.

4
Explore Tabs

Switch between tabs: Overview (task completion, project health), Team (assignee workload, performance), Timesheets (hours logged by project/employee), Deadlines (overdue tasks, upcoming milestones) and Comparison (period vs period).

Module Features

Everything you need to understand your project performance — all in one place.

📈
9 Live KPI Cards

Total Projects, Open Tasks, Completed Tasks, Overdue Tasks, Hours Logged, Avg Task Duration, On-Time Completion Rate, Tasks Created and Milestones Due — all with period-over-period indicators.

📊
Task Progress Charts

Task completion trend by day/week/month, stage distribution funnel and project health overview. Understand your team velocity at a glance.

👥
Team Performance

Assignee workload, tasks completed per person and average resolution time. Spot over-loaded team members and under-utilised capacity.

🔍
Smart Filters

Filter by Today, Last 7 Days, This Month, This Quarter, This Year or custom range. Stack with Project and Assignee filters for precise task drilldowns.

⚠
Deadline Tracker

Overdue tasks and upcoming milestones highlighted by priority. Never miss a delivery date with a real-time deadline heat map.

🔁
Period Comparison

Compare tasks completed, hours logged, on-time rate and new tasks against the previous equivalent period with side-by-side charts.

🕑
Timesheet Analysis

Hours logged by project, employee and task type. Track billable vs non-billable time and identify where effort is being spent.

📋
5 Analytical Tabs

Overview, Team, Timesheets, Deadlines and Comparison — each tab focuses on a specific dimension of your project data.

📱
Fully Responsive

Works on desktop, tablet and mobile. KPI cards reflow from 3 columns to 2 to 1, tabs collapse and all charts resize fluidly.

How to Use — Step by Step

A complete guide to getting the most out of your project analytics.

1
Install the Module

Go to Apps, search for WT Project Analytics Dashboard and click Install. Only Project and Web are required — all dependencies install automatically.

2
Open the Dashboard

From the Odoo home screen click the Project Analytics app tile. The dashboard opens instantly, loading all KPIs, charts and data for the default period (Today). Access is restricted to users with the Project / Manager or User role.

3
Set Your Filters

Use the top-bar filter strip to select a period, then optionally narrow by Project and Assignee. Click Refresh to reload all data.

4
Explore the Tabs

Switch between tabs: Overview (task completion, project health), Team (assignee workload, performance), Timesheets (hours logged by project/employee), Deadlines (overdue tasks, upcoming milestones) and Comparison (period vs period).
