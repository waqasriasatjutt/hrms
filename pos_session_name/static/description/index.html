POS Session Name

Display the active POS session name directly in your Point of Sale interface.

  • Shows the current POS session name in the POS interface
  • Improves clarity when working with multiple sessions
  • Ideal for multi-user and multi-counter environments
  • Lightweight and non-intrusive enhancement
  • Fully compatible with standard Odoo POS workflows

Step 1

Select the Point of Sale

Step 2

Click Open Register or Continue Selling to start the POS session.

POS Screen View

The session name is displayed clearly at the top of the POS product screen.
