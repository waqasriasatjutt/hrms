 # Módulo: Redención de Puntos Leal

Este módulo permite la integración entre Odoo y Leal para que los clientes puedan redimir sus puntos acumulados en Leal directamente desde el punto de venta (POS) o durante el proceso de facturación en Odoo.

## Características principales

Validación del número de identificación o correo del cliente con Leal.
Consulta de saldo de puntos disponible.
Redención de puntos como forma de pago o descuento en la orden de venta o factura.
Registro de las transacciones de redención en Odoo para trazabilidad.

## Requisitos

Odoo 17+ (adaptable a Odoo 17 o 18)
Conexión a internet desde el servidor de Odoo
Cuenta activa en Leal con credenciales de API
