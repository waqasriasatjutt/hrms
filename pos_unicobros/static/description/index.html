Configuración y Uso del Medio de Pago Unicobros

Punto de Venta (POS) – Odoo 18

Este módulo permite integrar la terminal de pago Unicobros con el Punto de Venta de Odoo 18, facilitando la gestión de cobros electrónicos de forma directa, segura y totalmente automatizada.

1. Creación del Método de Pago

Como primer paso, es necesario crear el método de pago que luego podrá ser utilizado en las distintas cajas del Punto de Venta.

Para ello, acceder a:

Punto de Venta → Configuración → Métodos de Pago

Una vez allí, hacer clic en “Nuevo” para crear un nuevo método de pago y completar el formulario con la siguiente información:

  • Nombre del método de pago:
    Definir un nombre de referencia identificable, por ejemplo: “POS Unicobros”.
  • Diario:
    Asignar el diario contable correspondiente según la operatoria definida (por ejemplo, Banco).
  • Integración:
    Seleccionar la opción “Terminal”. Esta selección habilitará el campo adicional “Integrar con”.
  • Integrar con:
    Seleccionar “Unicobros”.

2. Configuración de Credenciales Unicobros

Una vez seleccionada la integración con Unicobros, se deberán completar los siguientes campos obligatorios:

  • API Key de la entidad
  • Access Token de la entidad
  • POS Device ID

El POS Device ID corresponde al identificador de la terminal física de Unicobros con la cual se desea operar.

Este dato puede obtenerse directamente desde la terminal Unicobros, accediendo a:

Menú → Ajustes → Referencia

3. Asignación del Método de Pago a las Cajas

Una vez creado y configurado el método de pago, este podrá ser asignado a las cajas de Punto de Venta que lo requieran.

Para ello, ingresar a la configuración de cada caja y seleccionar el método de pago POS Unicobros dentro de los medios de pago habilitados.

4. Uso en el Punto de Venta

Con el método de pago correctamente configurado y asignado, este quedará disponible en la pantalla de cobros del Punto de Venta de Odoo.

El flujo de operación es el siguiente:

  1. El usuario selecciona POS Unicobros como método de pago.
  2. Odoo envía automáticamente la intención de pago a la terminal Unicobros.
  3. El cliente realiza el pago directamente en la terminal.
  4. Una vez finalizada la operación:
    • El resultado de la transacción se sincroniza automáticamente con Odoo.
    • El Punto de Venta refleja el estado del pago (aprobado o rechazado).
    • En caso de rechazo, Odoo informa el motivo correspondiente.

Este proceso garantiza una integración directa y segura entre Odoo y la terminal Unicobros, evitando cargas manuales y asegurando la trazabilidad de cada operación.
