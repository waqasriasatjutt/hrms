Captivea POS Auto Invoice

Overview

This app enables automatic invoice creation for each POS order. By default, Odoo leaves the 'Invoice' option unchecked during the checkout process. After installing this module, the option is checked by default on the payment screen, ensuring that an invoice is generated for every POS order.

How It Works

1

In the POS order screen, select any product and proceed to payment.


2

Prior to installation, users had to manually check the invoice option during checkout as per default odoo workflow.


3

Post-installation, the invoice option is enabled automatically and cannot be unchecked by the user.
