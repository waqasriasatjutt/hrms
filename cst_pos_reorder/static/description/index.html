POS One−Click Reorder
This Module allows cashiers to instantly recreate a previous order directly from the POS order history.
This feature is ideal for repeat customers and fast-paced environments, eliminating the need to manually add products again.

Detailed Features List

Instant Order Reorder

  • Recreate a previous POS order instantly from the order history with a single click. No need to manually add products again, saving valuable cashier time.

Preserves Original Configuration

  • Products are reordered using the exact same variants, quantities, discounts, and notes from the original order. The product configurator is intentionally skipped for faster checkout.

Works Only on Completed Orders

  • The reorder option is available only for finalized and synced POS orders, ensuring accuracy and preventing reordering of draft or in progress carts.

Seamless Odoo POS Integration

  • Fully built on top of Odoo's native POS behavior. No popups, no custom dialogs, and no workflow changes − it feels like a built in feature.
